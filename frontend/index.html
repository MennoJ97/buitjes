About Buitjes

Rainfall over the Netherlands in 5-minute steps: an hour of measured radar behind you, six hours of forecast ahead. Everything is self-hosted — the page talks only to this server.

Reading the timeline

Observed
What the radar actually measured.
Nowcast
First two hours ahead, mostly radar extrapolation.
Forecast
Beyond that, increasingly the weather model.

The forecast is seamless — that split is a reading aid, not a change of data source. Accuracy drops the further right you scrub.

Data & weather models

Precipitation comes from the KNMI Data Platform, licensed CC BY 4.0.

    • Open-Meteo temperature

      The KNMI product is precipitation only, so temperature comes from Open-Meteo's ensemble endpoint — which returns every member, giving the same kind of spread the rain forecast has. Fetched server-side.

    Mapping

    • MapLibre GL JS renderer

      Open-source GPU map rendering, served from this host rather than a CDN.

    • CARTO basemaps tiles

      Ground and label layers drawn separately so place names stay readable through the rain. Built from OpenStreetMap data.

    • OpenFreeMap tiles

      OpenStreetMap vector tiles, free and without a key. The high-contrast dark style is their Dark style recoloured here: quiet roads, white place names on a heavy halo, and the rain ramp left as the only real colour on the map.

    • OpenStreetMap standard tiles tiles

      The familiar OSM rendering, served by the OpenStreetMap Foundation. One image with the names drawn into it, so on this style they sit under the rain rather than over it.

    How it works

    • Push, not polling. A Python service subscribes to KNMI's MQTT notification service and ingests each file as it is announced, rather than repeatedly asking whether one has appeared.
    • Two grids, one raster. The forecast arrives as NetCDF on a lat/lon grid and the radar as KNMI HDF5 on a polar stereographic one; both are resampled onto a single Web Mercator raster so the map can stretch one canvas over them.
    • 16-bit WebP packing. Each rain rate is split across the red and green channels of a lossless WebP, so a whole 6-hour cycle is about a megabyte.
    • Colour on the GPU. A WebGL shader recombines those bytes and applies the colour scale, so frames can be recoloured without refetching. A Rust server hands out the finished frames.

    Credit

    Inspired by Nimbus by Yannick, which showed what a self-hosted KNMI radar viewer could be — the ensemble timeline, the WebP channel packing and the shader-side colour ramp are all ideas taken from it. This is an independent implementation.
